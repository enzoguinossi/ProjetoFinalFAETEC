## Requisitos

### 1. `globals.css` — tornar globais os tokens que só existem na tabela do plugin

Acrescentar ao bloco `@theme` (não alterar nem renomear nada existente):

```css
  --color-branco: #ffffff;
  --raio-lg: 8px;
  --raio-xl: 20px;
  --raio-pill: 26px;
```

### 2. Novo `tools/figma-export/tokens.ts` — parser único dos tokens globais

Exporta uma função que lê `GLOBALS_CSS` (de `config.ts`; reaproveite a mesma regex de
`diff.ts#lerTokensCss`, que já ignora comentários) e devolve:

```ts
{ cores: Record<string, string>, metricas: Record<string, number> }
```

Regras:
- `--color-<x>: <hex>` → `cores[x] = hex` (chave **sem** o prefixo `color-`).
- `--<x>: <rem|px|número>` (exceto `--color-*`, `--font-*` e valores `var(...)`) →
  `metricas[x] = px` (converter `rem` → px com base 16, como o `diff.ts#normalizar`).
- **Ignorar** os aliases legados do `:root` (`--green`, `--green-hover`, `--text-dark`,
  `--border-light`, `--hover-bg`, `--table-alt`, `--alert`): são duplicatas da paleta.
  Documente isso em comentário.
- Se não encontrar nenhum token, **lançar erro** (nunca exportar tabela vazia).

### 3. `harvest.ts` — levar os tokens no manifesto

Incluir `tokens` no objeto do manifesto (`scenes.json`), junto de `viewport`, `scale`,
`sceneServer`, `scenes` e `origem`.

### 4. `plugin/code.js` — consumir do manifesto com **upsert**

- Remover `TOKENS_COR` e `TOKENS_METRICA` hardcoded; usar `estado.tokens` (do manifesto).
- `garantirVariaveis`: garantir as coleções `Nexus / Cor` e `Nexus / Métrica`; para **cada**
  token:
  - se a variável já existe na coleção → **atualizar o valor do modo padrão**
    (`setValueForMode`);
  - se não existe → **criar**.
  - Não remover variáveis que não estão mais na lista (apenas registrar).
- `variavelDeCor` / `variavelDeRaio` passam a usar as tabelas vindas do manifesto.
- Falha ao atualizar/criar **não pode derrubar a importação**: usar `registrarFalha`.

### 5. `plugin-check.ts` — nova invariante do upsert

O mock já implementa `createVariableCollection`, `createVariable`, `setValueForMode`,
`getLocalVariableCollectionsAsync`, `getLocalVariablesAsync`, `getVariableByIdAsync`.
Acrescentar uma invariante que:
- confira que as variáveis de `Nexus / Cor` e `Nexus / Métrica` batem com os tokens do
  manifesto; **e**
- simule uma execução anterior (variável pré-existente com **valor antigo**) e comprove que
  o upsert **converge para o valor atual** — provando que "atualiza existentes" funciona.
- Se o manifesto não trouxer `tokens` (colheita antiga), **falhar** com mensagem clara
  mandando re-rodar `npm run figma:harvest`.
